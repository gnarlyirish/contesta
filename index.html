Questions owners ask

Will my customers know they're talking to AI?

Sofía sounds natural, but we never pretend she's a person. If a caller asks, she says she's the restaurant's virtual host. Most callers just care that someone picked up and got the order right.

What if it gets an order wrong?

Every order is read back with the total before it's sent, and every call is recorded so you can check. Week one runs only after hours, so you can see it work before you trust it with the rush.

Do I need a new phone number or new equipment?

No. You keep your number. We set up call forwarding so only the calls you miss (busy, no answer, closed) go to Contesta. Orders come to your phone by text.

Does it work with my POS?

Orders arrive as a clean text ticket today. Direct Clover, Square and Toast integrations are on the roadmap for restaurants that want them.

Can it handle Spanish callers?

Yes. It answers in the caller's language and switches mid-call if they do. It was built for kitchens where half the calls come in Spanish.

How long does setup take?

About three days. You send the menu, we build and test it with you, then turn on forwarding.
